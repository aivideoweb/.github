## 制作你的第一个五秒镜头

可以从[免费 H3 指南中的温馨房间练习](https://github.com/aivideoweb/best-free-minimax-h3/blob/main/docs/free-tool-prompts.md#user-content-videoweb)开始。源文提供英文和中文，下方是简体中文译例，无需再去提示词库查找即可练习。这是纯文字练习，不是已经生成的视频。

1. 打开[免费 MiniMax H3](https://videoweb.ai/cn/free-minimax-h3/)，将两个图片位置留空。
2. 粘贴下方提示词，选择横屏 **16:9**。免费输出为 5 秒、480p。
3. 完成页面要求的验证，提交一次并关注任务状态。返回视频后，先预览再下载。
4. 检查门框是否保持笔直、镜头运动是否平滑，以及结尾是否完整呈现椅子和灯。如果运动不连贯，下次就缩短镜头移动距离。

```text
生成一个五秒的连续镜头，画面比例为 16:9。
镜头起初静止在一扇敞开的木门外，然后缓慢向前推进，进入安静的阅读室。
窗边的窗帘轻轻摆动。结尾完整呈现椅子和灯。
保持门框笔直，房间布局不变。轻柔的室内环境声，没有对话或文字。
最后一秒保持平稳。不要切镜，也不要增加场景切换。
```

**改成你的场景：**先把“阅读室”换成你想拍的地方，例如一家小店，再把“椅子和灯”换成你希望在结尾呈现的物品。保留连续镜头、缓慢推进和平稳的最后一秒。每次只改一项要求，然后重新检查相同细节。

这项练习尚未经过生成实测。它用于生成文字描述的场景，单靠文字无法保留真实房间或产品的外观。若要用图片引导，需在免费表单中同时提供首帧和尾帧。需要更长的场景或其他输出设置时，可打开 [H3 模型页](https://videoweb.ai/cn/model/minimax-h3/)，查看选项和积分费用。

**还需要配乐？**打开 [AI 音乐生成器](https://videoweb.ai/cn/ai-music/)，选择可用模型和 Instrumental（纯音乐）模式，试着描述：“温暖的木吉他与轻柔打击乐，轻松的情绪，稳定的节奏，无人声，用于安静的产品演示。”生成前检查积分费用，再将音乐与视频对照试听。这段音乐提示词尚未生成验证。音乐创作是独立流程，最终配乐需要在后续剪辑时加入。
