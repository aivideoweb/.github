## 動画・画像・音楽をブラウザーで制作

[VideoWeb AI](https://videoweb.ai/) は、AI による動画生成、画像の作成・編集、音楽制作のツールをひとつのブラウザー上の作業スペースにまとめたサービスです。クリエイター、マーケティング担当者、電子商取引のチーム、教育者が利用できます。文章で描いたシーン、商品写真、絵コンテの1コマから始めてモデルを選び、コードを書くことなく次のプロジェクトの素材を制作できます。

商品の登場シーン、縦型のソーシャル動画、キャンペーン画像、授業の導入映像などを作れます。GitHub で公開している資料は、その次の疑問に役立ちます。**モデルに何をどう指示すればよいのか。生成された結果のどこを確認すればよいのか。**

| 作りたいもの | 最初に使うツール |
| --- | --- |
| アイデアをもとにした短いシーン | [テキストから動画を生成](https://videoweb.ai/text-to-video/) — 被写体、動き、カメラ、音を説明します |
| 商品写真や絵コンテに動きを加えた映像 | [画像から動画を生成](https://videoweb.ai/image-to-video/) — 画像を用意し、何を動かすか説明します |
| サムネイル、ポスター、修正した商品画像 | [AI 画像生成ツール](https://videoweb.ai/ai-image-generator/) — 制作内容を記述するか、編集箇所を指示します |
| 制作プロジェクト用の音楽 | [AI 音楽生成ツール](https://videoweb.ai/ai-music/) — 雰囲気と音楽の方向性から考えます |

## 初めての5秒カットを作る

1. [無料 MiniMax H3](https://videoweb.ai/free-minimax-h3/)を開きます。まずはテキストだけを使い、2つの画像欄は空にしておきます。
2. 下の説明を貼り付け、横長・縦長・正方形の構図を選びます。無料ページの記載は5秒・480pです。
3. 必要な認証を済ませ、1回送信して処理状況を確認します。動画が返ってきたら、ダウンロード前に内容を確認します。
4. カップの形、カメラの動き、最後の状態を確認します。次の試行では指示を1つだけ変えます。

```text
木のテーブルに置かれた、無地の青い陶器のカップを映す5秒間のワンカット。
カップは動かさない。最初の4秒間はカメラがゆっくり近づき、最後の1秒間は静止する。
左側の窓から柔らかな光が差し込む。
カップの形、持ち手、色、背景は変えない。
カットの切り替え、物の追加、文字、ロゴは入れない。
静かな室内の環境音のみで、話し声は入れない。
```

これは入門用の指示例であり、生成結果をテストしたものではありません。画像で誘導する場合は、無料フォームに開始フレームと終了フレームの両方を用意してください。長いシーンや別の出力設定が必要な場合は、[H3 モデルページ](https://videoweb.ai/model/minimax-h3/)を開いて、利用可能な設定とクレジット消費量を確認してください。

**音楽も必要ですか？** [AI 音楽](https://videoweb.ai/ai-music/)を開き、利用可能なモデルとInstrumental（ボーカルなし）モードを選んで、例えば「温かみのあるアコースティックギターと柔らかな打楽器。くつろいだ雰囲気、一定のテンポ、ボーカルなし。落ち着いた商品紹介用」と説明します。生成前に表示されるクレジット消費量を確認し、生成後は動画に合うか聴いて確かめてください。この音楽の指示例は生成テストを行っていません。音楽制作は別の工程であり、完成映像への追加は後の編集作業で行います。

## 教え合い、共有し、VideoWeb と提携する

[VideoWeb アフィリエイトプログラム](https://videoweb.ai/affiliate-program/)は、役立つチュートリアルや制作手順を紹介する動画クリエイター、ツールのレビュアー、マーケティング担当者、教育者向けです。

紹介されたユーザーが有効な紹介リンクから登録し、プラットフォームに紹介関係が記録されていることが必要です。どちらの報酬率も、**登録から60日以内**の対象注文にのみ適用されます。

| 報酬の対象となる紹介注文 | 公開されている報酬ルール |
| --- | --- |
| 初回の有効な有料注文 | 20% |
| 登録後60日以内の、2回目以降の有効な有料注文 | 10% |

参加手順：

1. [プログラムのページ](https://videoweb.ai/affiliate-program/)を開き、VideoWeb アカウントにログインします。
2. 提携者のプロフィールと報酬の受取情報を入力し、[アフィリエイト契約](https://videoweb.ai/affiliate-agreement/)を確認して同意します。
3. 承認後に紹介リンクを作成し、紹介による報酬が発生する関係を明示したチュートリアルやレビューで使用します。

参加資格、紹介の帰属、返金、対象外となる条件は契約に従います。収益は保証されません。現在の契約では、支払いを申請するには、**承認済みかつ受取可能な報酬が100米ドル以上**必要です。
