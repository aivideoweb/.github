## 브라우저에서 영상과 이미지, 음악을 만드는 작업 공간

[VideoWeb AI](https://videoweb.ai/)는 AI 영상 생성, 이미지 제작과 편집, 음악 도구를 하나의 브라우저 작업 공간에서 제공합니다. 크리에이터, 마케팅 담당자, 전자상거래 팀, 교육자를 위한 서비스입니다. 글로 쓴 장면 설명이나 제품 사진, 스토리보드 한 장에서 시작해 모델을 선택하고, 코드를 작성하지 않고도 다음 프로젝트에 쓸 소재를 만들 수 있습니다.

제품 공개 영상, 세로형 소셜 미디어 영상, 캠페인 이미지, 수업 도입 영상을 만들어 보세요. GitHub 자료는 그다음 질문에도 도움을 줍니다. **원하는 결과를 얻으려면 모델에 무엇을 어떻게 요청해야 할까요? 생성된 결과에서는 무엇을 확인해야 할까요?**

| 아이디어를 바탕으로 한 짧은 장면 | [텍스트로 영상 만들기](https://videoweb.ai/text-to-video/) — 피사체, 동작, 카메라, 소리를 설명하세요 |
| 제품 사진이나 스토리보드에 움직임을 더한 영상 | [이미지로 영상 만들기](https://videoweb.ai/image-to-video/) — 이미지를 제공하고 무엇이 움직이는지 설명하세요 |

## 첫 5초 숏 만들기

1. [무료 MiniMax H3](https://videoweb.ai/free-minimax-h3/)를 여세요. 우선 텍스트만 사용하고 이미지 입력란 두 개는 모두 비워 두세요.
2. 아래 설명을 붙여 넣고 가로, 세로, 정사각형 구도 중 하나를 선택하세요. 무료 페이지에는 5초·480p로 안내되어 있습니다.
3. 필요한 인증을 완료한 뒤 한 번 제출하고 요청 상태를 확인하세요. 영상이 나오면 다운로드하기 전에 먼저 검토하세요.
4. 컵 모양, 카메라 움직임, 마지막 장면을 확인하세요. 다음 시도에서는 지시 하나만 바꿔 보세요.

```text
나무 탁자 위에 놓인 무늬 없는 파란색 도자기 컵을 담은 5초짜리 단일 숏.
컵은 움직이지 않는다. 처음 4초 동안 카메라가 천천히 다가가고, 마지막 1초는 멈춘다.
왼쪽 창문에서 부드러운 빛이 들어온다.
컵 모양, 손잡이, 색상, 배경은 그대로 유지한다.
장면을 전환하지 말고, 물건이나 글자, 로고를 추가하지 않는다.
조용한 실내 환경음만 들리고 말소리는 없다.
```

이 설명은 입문용 예시이며, 생성 결과를 시험한 것은 아닙니다. 이미지로 장면을 유도하려면 무료 입력 양식에 첫 프레임과 마지막 프레임을 모두 제공하세요. 더 긴 장면이나 다른 출력 설정이 필요하다면 [H3 모델 페이지](https://videoweb.ai/model/minimax-h3/)에서 사용 가능한 옵션과 크레딧 비용을 확인하세요.

**배경 음악도 필요한가요?** [AI 음악](https://videoweb.ai/ai-music/)을 열고 이용 가능한 모델과 Instrumental(보컬 없는 연주곡) 모드를 선택한 다음, 예를 들어 이렇게 설명해 보세요. “따뜻한 어쿠스틱 기타와 부드러운 타악기, 편안한 분위기, 일정한 템포, 보컬 없이 차분한 제품 시연에 어울리는 음악.” 생성 전에 표시된 크레딧 비용을 확인하고, 생성 후에는 영상과 함께 들으며 어울리는지 검토하세요. 이 음악 설명은 생성 테스트를 거치지 않았습니다. 음악 제작은 별도 절차이며, 완성 영상에 넣는 작업은 이후 편집 단계에서 진행합니다.
