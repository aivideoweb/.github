## 動画・画像・音楽をブラウザーで制作

[VideoWeb AI](https://videoweb.ai/ja/) は、AI による動画生成、画像の作成・編集、音楽制作のツールをひとつのブラウザー上の作業スペースにまとめたサービスです。クリエイター、マーケティング担当者、電子商取引のチーム、教育者が利用できます。文章で描いたシーン、商品写真、絵コンテの1コマから始めてモデルを選び、コードを書くことなく次のプロジェクトの素材を制作できます。

商品の登場シーン、縦型のソーシャル動画、キャンペーン画像、授業の導入映像などを作れます。GitHub で公開している資料は、その次の疑問に役立ちます。**モデルに何をどう指示すればよいのか。生成された結果のどこを確認すればよいのか。**

| 作りたいもの | 最初に使うツール |
| --- | --- |
| アイデアをもとにした短いシーン | [テキストから動画を生成](https://videoweb.ai/ja/text-to-video/) — 被写体、動き、カメラ、音を説明します |
| 商品写真や絵コンテに動きを加えた映像 | [画像から動画を生成](https://videoweb.ai/ja/image-to-video/) — 画像を用意し、何を動かすか説明します |
| サムネイル、ポスター、修正した商品画像 | [AI 画像生成ツール](https://videoweb.ai/ja/ai-image-generator/) — 制作内容を記述するか、編集箇所を指示します |
| 制作プロジェクト用の音楽 | [AI 音楽生成ツール](https://videoweb.ai/ja/ai-music/) — 雰囲気と音楽の方向性から考えます |

## 初めての5秒カットを作る

[無料 H3 ガイドの温かみのある部屋の練習例](https://github.com/aivideoweb/best-free-minimax-h3/blob/main/docs/free-tool-prompts.md#user-content-videoweb)から始めてみましょう。元の資料は英語・中国語で、以下には日本語訳を載せています。プロンプト集を探さず、このページから練習できます。これはテキストだけで行う練習であり、生成済みの動画ではありません。

1. [無料 MiniMax H3](https://videoweb.ai/ja/free-minimax-h3/)を開き、2つの画像欄は空にしておきます。
2. 下のプロンプトを貼り付け、横長の **16:9** を選びます。無料出力は5秒・480pです。
3. 必要な認証を済ませ、1回送信して処理状況を確認します。動画が返ってきたら、ダウンロード前にプレビューします。
4. 戸口の枠がまっすぐか、カメラが滑らかに動くか、最後に椅子とランプが全体まで見えるかを確認します。動きが不自然になったら、次はカメラの移動距離を短くします。

```text
5秒間のワンカットを、16:9で作成する。
開いた木の扉の外でカメラを静止させた状態から、静かな読書室へゆっくり前進する。
窓辺のカーテンがかすかに揺れている。最後は椅子とランプの全体が見える構図にする。
戸口の枠はまっすぐに保ち、部屋の配置は変えない。穏やかな室内の環境音のみで、
会話や文字は入れない。
最後の1秒は落ち着いた画面を保つ。カットの切り替えや余分な場面転換は入れない。
```

**自分の場面に変えるには：**まず「読書室」を小さなお店など、作りたい場所に置き換えます。「椅子とランプ」も、最後に見せたい物に変えましょう。ワンカット、ゆっくりしたカメラ移動、落ち着いた最後の1秒は残します。指示は1つずつ変え、その都度同じ点を確認してください。

この練習例は生成テストを行っていません。文章で説明した場面を作るもので、テキストだけで実在の部屋や商品の外見を保つことはできません。画像で誘導する場合は、無料フォームに開始フレームと終了フレームの両方を用意してください。長いシーンや別の出力設定が必要な場合は、[H3 モデルページ](https://videoweb.ai/ja/model/minimax-h3/)で選択肢とクレジット消費量を確認してください。

**音楽も必要ですか？** [AI 音楽](https://videoweb.ai/ja/ai-music/)を開き、利用可能なモデルとInstrumental（ボーカルなし）モードを選んで、例えば「温かみのあるアコースティックギターと柔らかな打楽器。くつろいだ雰囲気、一定のテンポ、ボーカルなし。落ち着いた商品紹介用」と説明します。生成前に表示されるクレジット消費量を確認し、生成後は動画に合うか聴いて確かめてください。この音楽の指示例は生成テストを行っていません。音楽制作は別の工程であり、完成映像への追加は後の編集作業で行います。
