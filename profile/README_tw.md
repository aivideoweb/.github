## 在瀏覽器裡創作影片、圖片與音樂

[VideoWeb AI](https://videoweb.ai/) 將 AI 影片生成、圖片創作與編輯，以及音樂工具整合在同一個瀏覽器工作區，供創作者、行銷人員、電商團隊與教育工作者使用。從一段場景描述、一張產品照片或分鏡圖開始，選擇模型，為下一個專案製作素材，無須撰寫程式碼。

你可以製作產品亮相影片、直式社群短片、行銷圖片或課程開場。我們的 GitHub 資源進一步協助你回答：**該如何告訴模型我要做什麼？生成結果又該檢查哪些地方？**

| 想製作什麼 | 從哪裡開始 |
| --- | --- |
| 將想法變成一段短場景 | [文字生成影片](https://videoweb.ai/text-to-video/) — 描述主體、動作、鏡頭與聲音 |
| 讓產品照片或分鏡圖動起來 | [圖片生成影片](https://videoweb.ai/image-to-video/) — 提供圖片，並描述哪些部分要移動 |

## 製作你的第一個五秒鏡頭

1. 開啟[免費 MiniMax H3](https://videoweb.ai/free-minimax-h3/)。先只用文字，將兩個圖片欄位留空。
2. 貼上下方描述，選擇橫式、直式或正方形構圖。免費頁標示為 5 秒、480p。
3. 完成所需驗證，送出一次，並追蹤請求狀態。影片回傳後，先檢查再下載。
4. 檢查杯子形狀、鏡頭運動與結尾。下次嘗試時只更改一項指示。

```text
一個五秒的連續鏡頭：一只素面藍色陶瓷杯放在木桌上。
杯子保持靜止。前四秒鏡頭緩緩推近，最後一秒停住。
柔和的窗光從左側照入。
保持杯子形狀、把手、顏色與背景不變。
不要切換鏡頭、添加物件、文字或標誌。
安靜的室內環境聲，沒有說話聲。
```

這是一段入門創作描述，並非經過實測的生成結果。若要使用圖片引導，請在免費表單中同時提供開頭與結尾影格。若需要更長的場景或其他輸出設定，請開啟 [H3 模型頁](https://videoweb.ai/model/minimax-h3/)，查看可用選項與點數費用。

**需要配樂嗎？**開啟 [AI 音樂](https://videoweb.ai/ai-music/)，選擇可用模型與Instrumental（純音樂）模式，並輸入類似這樣的描述：「溫暖的木吉他搭配輕柔打擊樂，輕鬆的情緒、穩定的節奏、無人聲，適合平靜的產品展示。」生成前請確認畫面顯示的點數費用，再將音樂搭配影片試聽。這段音樂描述尚未經過生成測試。音樂創作是獨立流程，需在後續剪輯時加入成片。
