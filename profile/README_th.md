## พื้นที่สร้างสรรค์วิดีโอ ภาพ และดนตรี

[VideoWeb AI](https://videoweb.ai/) รวมการสร้างวิดีโอด้วยปัญญาประดิษฐ์ การสร้างและแก้ไขภาพ ตลอดจนเครื่องมือดนตรีไว้ในพื้นที่ทำงานบนเบราว์เซอร์ สำหรับผู้สร้างเนื้อหา นักการตลาด ทีมอีคอมเมิร์ซ และผู้สอน เริ่มจากคำบรรยายฉาก ภาพสินค้า หรือภาพสตอรีบอร์ด แล้วเลือกโมเดลเพื่อพัฒนาสื่อสำหรับโครงการถัดไปโดยไม่ต้องเขียนโค้ด

คุณสามารถสร้างวิดีโอเปิดตัวสินค้า คลิปแนวตั้งสำหรับสื่อสังคมออนไลน์ ภาพแคมเปญ หรือช่วงเปิดบทเรียน แหล่งข้อมูลบน GitHub ของเราช่วยตอบคำถามถัดไปว่า **ควรขอให้โมเดลสร้างอะไร และควรตรวจอะไรในผลลัพธ์?**

| สิ่งที่คุณอยากสร้าง | เริ่มที่ไหน |
| --- | --- |
| ฉากสั้นจากไอเดีย | [ข้อความเป็นวิดีโอ](https://videoweb.ai/text-to-video/) — บรรยายตัวแบบ การกระทำ กล้อง และเสียง |
| ภาพเคลื่อนไหวจากภาพสินค้าหรือสตอรีบอร์ด | [ภาพเป็นวิดีโอ](https://videoweb.ai/image-to-video/) — ส่งภาพและอธิบายว่าส่วนใดเคลื่อนไหว |
| ภาพขนาดย่อ โปสเตอร์ หรือภาพสินค้าที่ปรับแก้ | [เครื่องมือสร้างภาพด้วยปัญญาประดิษฐ์](https://videoweb.ai/ai-image-generator/) — เขียนคำอธิบายหรือระบุสิ่งที่ต้องการแก้ไข |
| ดนตรีสำหรับโครงการสร้างสรรค์ | [เครื่องมือสร้างดนตรีด้วยปัญญาประดิษฐ์](https://videoweb.ai/ai-music/) — เริ่มจากอารมณ์และแนวทางดนตรี |

1. เปิด [MiniMax H3 ฟรี](https://videoweb.ai/free-minimax-h3/) เริ่มด้วยข้อความอย่างเดียวและเว้นช่องภาพทั้งสองไว้
2. วางคำอธิบายด้านล่าง แล้วเลือกภาพแนวนอน แนวตั้ง หรือสี่เหลี่ยมจัตุรัส หน้าฟรีระบุ 5 วินาที / 480p
3. ทำการยืนยันตามที่หน้าบริการกำหนด ส่งคำขอหนึ่งครั้ง แล้วติดตามสถานะ ตรวจคลิปที่ได้รับก่อนดาวน์โหลด
4. ตรวจรูปทรงถ้วย การเคลื่อนกล้อง และตอนจบ ในครั้งถัดไปให้เปลี่ยนคำสั่งเพียงข้อเดียว

```text
ช็อตเดียวต่อเนื่องยาวห้าวินาทีของถ้วยเซรามิกสีน้ำเงินล้วนบนโต๊ะไม้
ถ้วยอยู่นิ่ง กล้องค่อย ๆ เคลื่อนเข้าใกล้ในสี่วินาทีแรก
จากนั้นหยุดนิ่งหนึ่งวินาที แสงนุ่มจากหน้าต่างส่องเข้าทางซ้าย
คงรูปทรงถ้วย หูจับ สี และพื้นหลังเดิม
ไม่มีการตัดภาพ ไม่เพิ่มสิ่งของ ตัวอักษร หรือตราสัญลักษณ์ มีเสียงบรรยากาศห้องที่เงียบสงบ ไม่มีเสียงพูด
```

นี่คือคำอธิบายสำหรับเริ่มต้น ยังไม่ใช่ผลลัพธ์ที่ผ่านการทดสอบสร้างจริง หากต้องการใช้ภาพกำหนดทิศทาง ให้ใส่ทั้งเฟรมแรกและเฟรมสุดท้ายในแบบฟอร์มฟรี หากต้องการฉากยาวขึ้นหรือการตั้งค่าผลลัพธ์แบบอื่น ให้เปิด[หน้าโมเดล H3](https://videoweb.ai/model/minimax-h3/)เพื่อตรวจตัวเลือกและค่าเครดิตที่มีให้ใช้

**ต้องการดนตรีประกอบด้วยไหม?** เปิด[เครื่องมือสร้างดนตรีด้วยปัญญาประดิษฐ์](https://videoweb.ai/ai-music/) เลือกโมเดลที่มีให้ใช้และโหมดดนตรีบรรเลง แล้วบรรยาย เช่น “กีตาร์โปร่งโทนอุ่นกับเครื่องกระทบเบา ๆ อารมณ์ผ่อนคลาย จังหวะสม่ำเสมอ ไม่มีเสียงร้อง สำหรับการสาธิตสินค้าที่สงบเรียบง่าย” ตรวจค่าเครดิตที่แสดงก่อนสร้าง จากนั้นลองฟังเทียบกับวิดีโอ คำอธิบายดนตรีนี้ยังไม่ผ่านการทดสอบสร้างจริง การสร้างดนตรีเป็นขั้นตอนแยกต่างหาก ส่วนการใส่ดนตรีลงในงานตัดต่อฉบับสุดท้ายเป็นขั้นตอนภายหลัง
