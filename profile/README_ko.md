## 브라우저에서 영상과 이미지, 음악을 만드는 작업 공간

[VideoWeb AI](https://videoweb.ai/ko/)는 AI 영상 생성, 이미지 제작과 편집, 음악 도구를 하나의 브라우저 작업 공간에서 제공합니다. 크리에이터, 마케팅 담당자, 전자상거래 팀, 교육자를 위한 서비스입니다. 글로 쓴 장면 설명이나 제품 사진, 스토리보드 한 장에서 시작해 모델을 선택하고, 코드를 작성하지 않고도 다음 프로젝트에 쓸 소재를 만들 수 있습니다.

제품 공개 영상, 세로형 소셜 미디어 영상, 캠페인 이미지, 수업 도입 영상을 만들어 보세요. GitHub 자료는 그다음 질문에도 도움을 줍니다. **원하는 결과를 얻으려면 모델에 무엇을 어떻게 요청해야 할까요? 생성된 결과에서는 무엇을 확인해야 할까요?**

- **아이디어를 바탕으로 한 짧은 장면** — [텍스트로 영상 만들기](https://videoweb.ai/ko/text-to-video/) — 피사체, 동작, 카메라, 소리를 설명하세요
- **제품 사진이나 스토리보드에 움직임을 더한 영상** — [이미지로 영상 만들기](https://videoweb.ai/ko/image-to-video/) — 이미지를 제공하고 무엇이 움직이는지 설명하세요
- **썸네일, 포스터 또는 수정한 제품 이미지** — [AI 이미지 생성기](https://videoweb.ai/ko/ai-image-generator/) — 제작 요구 사항을 적거나 편집할 내용을 지정하세요
- **창작 프로젝트에 쓸 음악** — [AI 음악 생성기](https://videoweb.ai/ko/ai-music/) — 분위기와 음악적 방향부터 정하세요

## 첫 5초 숏 만들기

[무료 H3 안내의 아늑한 방 연습 예시](https://github.com/aivideoweb/best-free-minimax-h3/blob/main/docs/free-tool-prompts.md#user-content-videoweb)로 시작해 보세요. 원본은 영어와 중국어로 제공되며, 아래에는 한국어 번역 예시를 실었습니다. 자료실을 따로 찾지 않고 여기서 바로 연습할 수 있습니다. 텍스트만 사용하는 연습이며, 생성된 영상 결과물이 아닙니다.

1. [무료 MiniMax H3](https://videoweb.ai/ko/free-minimax-h3/)를 열고 이미지 입력란 두 개를 모두 비워 두세요.
2. 아래 프롬프트를 붙여 넣고 가로 **16:9**를 선택하세요. 무료 출력은 5초·480p입니다.
3. 필요한 인증을 마친 뒤 한 번 제출하고 요청 상태를 확인하세요. 영상이 나오면 다운로드 전에 미리 보세요.
4. 문틀이 곧게 유지되는지, 카메라가 부드럽게 움직이는지, 마지막에 의자와 램프 전체가 보이는지 확인하세요. 움직임이 어색해지면 다음 시도에서는 카메라 이동 거리를 줄이세요.

```text
16:9 비율로 5초짜리 단일 숏을 만든다.
열린 나무 문 밖에서 카메라가 멈춰 있는 상태로 시작해, 조용한 독서실 안으로 천천히 전진한다.
창가의 커튼이 살짝 흔들린다. 마지막에는 의자와 램프 전체가 보이도록 한다.
문틀을 곧게 유지하고 방의 배치를 바꾸지 않는다. 잔잔한 실내 환경음만 넣고,
대화나 글자는 넣지 않는다.
마지막 1초는 차분하게 유지한다. 컷을 전환하거나 별도의 장면 전환을 추가하지 않는다.
```

**내 장면으로 바꾸기:** 먼저 “독서실”을 작은 가게처럼 원하는 장소로 바꿔 보세요. “의자와 램프”도 마지막에 보여 주고 싶은 물건으로 바꾸세요. 하나로 이어지는 숏, 느린 카메라 이동, 차분한 마지막 1초는 유지하세요. 지시는 한 번에 하나씩 바꾸고 같은 세부 사항을 다시 확인하세요.

이 연습 예시는 생성 테스트를 거치지 않았습니다. 글로 설명한 장면을 만드는 예시이며, 텍스트만으로 실제 방이나 제품의 외관을 유지할 수는 없습니다. 이미지로 장면을 유도하려면 무료 입력 양식에 첫 프레임과 마지막 프레임을 모두 제공하세요. 더 긴 장면이나 다른 출력 설정이 필요하다면 [H3 모델 페이지](https://videoweb.ai/ko/model/minimax-h3/)에서 선택지와 크레딧 비용을 확인하세요.
