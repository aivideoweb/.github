## 制作你的第一个五秒镜头

1. 打开[免费 MiniMax H3](https://videoweb.ai/free-minimax-h3/)，先只用文字，将两个图片位置留空。
2. 粘贴下方描述，选择横屏、竖屏或方形。免费页标明输出为 5 秒、480p。
3. 完成页面要求的验证，提交一次并关注任务状态。返回视频后，先检查再下载。
4. 检查杯子形状、镜头运动和结尾。下次尝试时，只修改一项要求。

```text
一个五秒的连续镜头：一只纯蓝色陶瓷杯放在木桌上。
杯子保持静止。前四秒镜头缓慢推近，最后一秒停住。
柔和的窗光从左侧照入。保持杯身、把手、颜色和背景不变。
不要切镜，不要添加物品、文字或标志。
声音是安静的室内环境声，没有人声。
```

这是一段入门提示词，尚未生成验证。若要用图片引导，需在免费表单中同时提供首帧和尾帧。需要更长的场景或其他输出设置时，可打开 [H3 模型页](https://videoweb.ai/model/minimax-h3/)，查看当前选项和积分费用。

**还需要配乐？**打开 [AI 音乐生成器](https://videoweb.ai/ai-music/)，选择可用模型和 Instrumental（纯音乐）模式，试着描述：“温暖的木吉他与轻柔打击乐，轻松的情绪，稳定的节奏，无人声，用于安静的产品演示。”生成前检查积分费用，再将音乐与视频对照试听。这段音乐提示词尚未生成验证。音乐创作是独立流程，最终配乐需要在后续剪辑时加入。
